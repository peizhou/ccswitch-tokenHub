## English

**TokenHub is an AI API key manager and multi-model chat app**—one place to store keys, talk to any model, and route Cursor, agents, and other tools to OpenAI, Claude, Gemini, DeepSeek, Qwen, Grok, and 300+ models via OpenRouter.

> This repository is a **private product codebase**. We do not open-source the implementation. Below: **what the app does**, **core highlights**, and **download links**.

### Highlights

| | |
|---|---|
| **🔐 Security first** | Keys encrypted on-device · local proxy on `127.0.0.1` · no cloud upload · log sanitization · one-tap key rotation · config health tags (GREEN / YELLOW / RED / BLACK) |
| **🔀 Switch freely** | Built-in chat—change models mid-conversation · Model Plaza to browse, filter, and compare 300+ models · platform key or BYOK in one workflow |
| **⏻ One-tap on/off** | Home-screen switch—instantly **allow or block all** outbound AI calls from connected tools (sleep without worry) |

### What you can do

- **Manage every AI key** in one vault—one distributed key (`sk-…`) or BYOK
- **Connect agents fast**—one-tap setup for OpenClaw, Claude Code, Codex, Gemini CLI, Hermes, Cursor, Cherry Studio, and more
- **See every dollar**—dashboard and logs for usage, model cost, and key balance
- **BYOK local forward** (optional)—requests go straight from your device to the provider; keys need not pass a relay
- **On-device Gemma 4**—offline-capable local model (`tokenhub-local/gemma4-e2b`); weights stay in the app sandbox
- **Pay your way**—Apple IAP, Stripe, WeChat Pay

### 还能做什么

- **一处管理**所有 AI 密钥——分发密钥（`sk-…`）或 BYOK
- **一键配置** OpenClaw、Claude Code、Codex、Gemini CLI、Hermes、Cursor、Cherry Studio 等 Agent
- **花费可视**——看板与日志掌握词元消耗、模型成本与余额
- **BYOK 本地转发**（可选）——请求从本机直达上游，密钥不经中转
- **内嵌 Gemma 4**——端侧离线可用（`tokenhub-local/gemma4-e2b`），权重留在应用沙盒
- **多种充值**——Apple 内购、Stripe、微信支付
